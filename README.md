# Portfolio d'Abdeljabbar Benhaddou

Portfolio statique prêt pour GitHub Pages.

## Contenu

- `index.html` : structure et contenu
- `style.css` : design responsive
- `script.js` : navigation, animations et année automatique
- `assets/` : CV, logo Dark Land Project et favicon

## Mise en ligne

Déposez tout le contenu de ce dossier à la racine du dépôt GitHub Pages. Ne modifiez pas les noms des fichiers ou du dossier `assets`.

## Ajouter un justificatif de certification

Ajoutez le PDF ou l'image dans `assets/certifications/`, puis remplacez le bouton désactivé de la carte concernée par un lien vers le fichier. Pour une certification vérifiable en ligne, utilisez de préférence l'URL officielle et le numéro d'identification fourni par l'organisme.

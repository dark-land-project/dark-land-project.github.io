# Portfolio d'Abdeljabbar Benhaddou

Portfolio statique prêt pour GitHub Pages.

## Publication

1. Créez un dépôt public nommé `votreidentifiant.github.io`.
2. Importez tout le contenu de ce dossier à la racine du dépôt.
3. Ouvrez **Settings > Pages**.
4. Choisissez **Deploy from a branch**, puis `main` et `/ (root)`.
5. Enregistrez et attendez quelques minutes.

Le portfolio sera disponible à l'adresse `https://votreidentifiant.github.io`.
